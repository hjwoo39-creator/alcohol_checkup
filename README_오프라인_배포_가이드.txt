============================================================
       음주운전 예방 자가진단 시스템 오프라인 배포 및 사용 매뉴얼
============================================================

본 자가진단 시스템은 인터넷이 전혀 연결되지 않는 오프라인 환경(교육장, 교실 등)의 
컴퓨터에서도 정상 작동할 수 있도록 모든 외부 라이브러리와 실행 엔진을 폴더 내에 
포팅(로컬화)해 두었습니다. 

이 폴더를 통째로 복사해서 인터넷이 되지 않는 다른 컴퓨터의 바탕화면 등에 붙여넣기만 하면 
아무런 추가 설치 없이 즉시 실행할 수 있습니다.


------------------------------------------------------------
1. 폴더 주요 구성 및 역할
------------------------------------------------------------
- [start-dashboard.bat] : 시스템을 구동하고 대시보드를 바로 띄워주는 "원클릭 실행 파일"입니다.
- [bin/node.exe]        : 인터넷이 안 되는 PC에 별도로 Node.js를 설치하지 않아도 작동을 보장하는 포터블 무설치 서버 엔진입니다.
- [chart.js]            : 통계 그래프(유형 분포 및 심리분석 차트)를 오프라인 상태에서도 온전히 그려내는 로컬 차트 라이브러리입니다.
- [index.html]          : 학생(교육 참가자)이 접속하여 자가진단을 수행하는 화면입니다.
- [dashboard.html]      : 교수자(강사)가 실시간으로 통계를 확인하고 데이터를 정렬, 상세조회, 삭제할 수 있는 어드민 대시보드 화면입니다.
- [server.js]           : 자가진단 데이터를 받아서 누적 저장 및 대시보드와 통신하는 핵심 서버 파일입니다.


------------------------------------------------------------
2. 실행 방법 (서버 및 대시보드 가동)
------------------------------------------------------------
1. 복사해 온 프로젝트 폴더 내에 있는 [start-dashboard.bat] 파일을 더블 클릭하여 실행합니다.
2. 검은색 터미널(CMD) 창이 켜지며 "폴더 내 포터블 Node.js 엔진으로 서버를 시작합니다." 라는 메시지가 나타납니다.
3. 약 3초 뒤, 기본 웹 브라우저(Edge, Chrome 등)가 열리며 자동으로 교수자 대시보드(http://localhost:3000/dashboard.html) 화면이 뜹니다.
※ 실행 중인 검은색 터미널 창을 강제로 닫으면 서버가 종료되므로, 시스템 사용 중에는 터미널 창을 최소화해 두고 닫지 마십시오.


------------------------------------------------------------
3. 교육 참가자(학생) 진단 접속 및 응답 수집 방법
------------------------------------------------------------
자가진단을 진행할 PC의 가동 환경에 따라 아래 두 가지 방법 중 알맞은 형태를 선택하여 진행합니다.

방법 [A] : 교육장 와이파이(Local LAN)를 통해 스마트폰/태블릿으로 참여하는 경우
   - 조건: 대시보드가 실행된 메인 PC와 학생들이 소지한 모바일 기기가 "동일한 공유기(와이파이)"에 연결되어 있어야 합니다. (인터넷 신호 연결은 무관)
   1. 교수자 대시보드 화면 상단(학생 접속 안내 카드)에 표시된 주소(예: http://192.168.0.XX:3000/index.html)를 칠판에 적어주거나, 화면에 나타난 QR코드를 안내합니다.
   2. 학생들이 본인의 스마트폰 카메라로 대시보드 화면의 QR코드를 스캔하면 오프라인 상태에서도 즉시 학생용 자가진단 페이지로 이동합니다.
   3. 학생들이 검사를 완료하고 [결과 제출]을 누르면, 메인 PC 대시보드의 참여 인원수와 통계 차트들이 실시간으로 즉시 갱신됩니다.

방법 [B] : 한 대의 단독 오프라인 PC에서 돌아가며 자가진단을 하는 경우
   - 조건: 메인 PC 단 한 대만 있고 와이파이나 타 기기 접속 환경이 전혀 제공되지 않는 환경일 때
   1. 대시보드 화면의 주소창에서 http://localhost:3000/index.html 주소를 복사합니다.
   2. 브라우저의 새 탭을 열고 해당 주소로 접속하면 바로 자가진단 테스트를 할 수 있습니다.
   3. 피교육자가 자가진단을 마친 뒤 제출하면 브라우저 결과 리포트(인쇄용)를 저장/출력할 수 있으며, 기존 대시보드 탭으로 돌아가면 해당 데이터가 바로 통계에 반영되어 누적됩니다.


------------------------------------------------------------
4. 주의사항 및 문제 해결 (Troubleshooting)
------------------------------------------------------------
- 윈도우 방화벽 경고 발생 시
  배치 파일을 처음 실행할 때 "Windows 보안 경고(방화벽 차단)" 창이 나타날 수 있습니다.
  스마트폰 등 외부 기기에서의 접속(방법 A)을 허용하려면 반드시 [개인 네트워크]와 [공용 네트워크] 모두 체크한 뒤 [액세스 허용] 버튼을 눌러주셔야 정상 통신이 가능합니다.

- 대시보드 사용 종료 후 서버 끄기
  대시보드 사용을 마치신 뒤에는 실행 시 함께 켜진 검은색 터미널(CMD) 창을 닫아주시면 서버가 안전하게 종료됩니다.

- 폰트 및 인터넷 리소스 안내
  인터넷이 차단된 PC이므로 기본 구글 폰트 등 외부 폰트는 윈도우 시스템 내장 폰트(맑은 고딕 등)로 자동 대체되어 깔끔하게 나타나며, 그 외 모든 CSS/JS 및 차트 기능은 100% 정상 작동합니다.
